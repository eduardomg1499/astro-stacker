# Zenith Astro Stacker — Releases

Este repositorio aloja **únicamente los releases descargables** de Zenith Astro Stacker:
instaladores para macOS (`.dmg`) y Windows (`.exe`), los artefactos del updater
(`.app.tar.gz` + `.sig`) y `latest.json` para el auto-actualizador.

➡️ **Descargas:** mira la sección **Releases** de este repositorio.

El **código fuente** del proyecto se mantiene en un repositorio aparte (privado).
